# Contributing

Pull requests are welcome. For a bigger change, please open an issue first so we can talk it through.

Report bugs in this repo's Issues. Include your system, and for Linux, your desktop and screen setup.
Please don't attach recordings or screenshots that show anything private, because this repo is public.

## Running the tests

- **macOS app:** `scripts/test.sh`. See "Developing" in the [README](README.md) for setup.
- **Fedora app:** in `desktop/`, run `npm ci`, then `npm test`. It needs Node.js LTS and ffmpeg.
